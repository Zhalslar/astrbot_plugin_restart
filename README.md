## 🤝 介绍

用命令重启、定时自动重启 AstrBot

## 📦 安装

在astrbot的插件市场搜索astrbot_plugin_restart，点击安装即可

## ⌨️ 使用说明

### 命令表

|     命令      |                    说明                    |
|:-------------:|:-----------------------------------------------:|
| 重启   | 重启 AstrBot  |
| 定时重启 HH:MM   | 在指定时间点（如12:30）重启 AstrBot  |
